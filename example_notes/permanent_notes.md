# Permanent Notes

Create permanent notes by reviewing fleeting notes and literature notes together.
Look for connections, agreements, and contradictions between their ideas.
Consider whether these relationships suggest a new insight or a question worth
exploring.

Each permanent note should develop one idea. Write concisely and provide enough
context for another reader to understand it without knowing the background that
led you to write it.

## Source

Sönke Ahrens, *How to Take Smart Notes*.
